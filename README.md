# Noven

Expo habit-tracking application with Firebase configuration, shared UI, and logic tests.

[Source](https://github.com/Up-to-code/Noven) · [Issues](https://github.com/Up-to-code/Noven/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Expo, React Native, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/Noven.git
cd Noven
```

Requires Bun and bun.

```sh
bun install
bun run start
```

## Available commands

| Command | Purpose |
| --- | --- |
| `bun run start` | Start the configured application |
| `bun run typecheck` | Check types |
| `bun run android` | Run the Android workflow |
| `bun run ios` | Run the iOS workflow |
| `bun run web` | Run the web workflow |
